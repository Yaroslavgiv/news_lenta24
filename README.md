# Lenta24

Современный агрегатор новостей на Flutter. Главная лента Lenta.ru дополнена отдельной вкладкой с другими редакциями: РИА Новости, Хабр, ТАСС, Интерфакс, Коммерсантъ, Известия, Газета.ру и Meduza.

## Что умеет приложение

- Нижняя навигация из трёх разделов: **Лента**, **24 часа**, **Источники**
- Карусель главных материалов и список последних новостей Lenta.ru
- Отдельная страница сторонних RSS-источников
- Поиск по заголовкам и тексту с подсветкой совпадений
- Прочитанные материалы, кнопка «отметить всё», локальный кэш Hive
- Связанные материалы на экране новости
- Адаптивная вёрстка для портретной и альбомной ориентации

## Стек

- Flutter / Dart
- Riverpod + Bloc
- Hive
- dart_rss, http, cached_network_image, carousel_slider

## Структура

```
lib/
  app.dart
  main.dart
  core/          тема, провайдеры, утилиты
  data/          модели, каталог источников, репозиторий RSS
  features/
    shell/       нижняя навигация
    feed/        лента Lenta.ru и новости за 24 часа
    sources/     каталог и ленты сторонних изданий
    search/      поиск
    detail/      страница новости
    shared/      карточки, карусель, состояния загрузки
```
